## 4. 原始功能状态

### 已经实现

- 无表头 CSV 读取、列名补充与时间戳转 `long`。
- Spark 本地模式与 DataFrame 缓存。
- 总记录数、用户数、商品数、类别数统计。
- `pv/cart/fav/buy` 行为计数与事件占比。
- 浏览/加购/收藏到购买的简单事件数比值。
- 购买用户数与用户购买率。
- 用户活跃度、购买频率和购买力分层。
- 用户画像宽表。
- A/F/R 用户价值评分与价值等级。

### 部分实现

- 数据清洗：仅有类型转换，没有字段数、空值、枚举、ID 或时间异常的系统校验。
- 配置：数据路径硬编码为本机绝对路径。
- 结果展示：只输出控制台；有一张历史截图，但没有可复现的导出或页面流程。

### 未实现

- 数据集管理、字段映射、能力检测、通用适配器。
- ODS/DWD/DWS/ADS 数仓落地。
- Hive、MySQL、JDBC。
- REST API、异步任务、任务日志与结果版本。
- 前端应用与图表服务。
- 自动化测试、部署脚本和完整运行说明。

## 5. 构建验证

为避免写入历史目录，将 `pom.xml` 与 `src` 复制到审计临时目录，以 JDK 17 和本机 Maven 离线依赖执行 `mvn compile`，结果通过。

当前终端默认 `JAVA_HOME` 指向 JDK 8，不能直接满足项目的 Java 17 编译配置；本机同时安装了 `C:\Program Files\Java\jdk-17`。这是环境选择问题，不是源代码编译错误。

## 7. 审计结论

A 不适合作为 V3 主工程：代码为单文件原型、没有服务层和测试，且工程化程度明显低于 B。但 A 必须继续作为原始基线、正式数据源和作者开发痕迹来源。A 的任何历史文件均不应被覆盖或移动。
